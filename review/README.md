# Design-review repro testbench

`tb_repro.v` runs a 21-instruction program (generated by `asm.py` into `prog.hex`) on a single
`riscv_ooo_core` with a byte-accurate data memory, then checks 8 results. On the imported RTL,
6 checks FAIL, demonstrating: JAL treated as JALR, wrong AUIPC result, a load forwarding from a
younger store, and byte-store forwarding returning the wrong bytes.

Run from the repo root:

    python3 review/asm.py            # writes prog.hex in the current directory
    iverilog -g2012 -DSIM -I rtl/core -o r.vvp rtl/core/*.v review/tb_repro.v
    vvp r.vvp

Or simply `make sim-repro`.

Status: on the imported RTL 5 of 8 checks fail (6 before the testbench stopped
the program wrapping round at 0x100). With the P1 fixes on branch
`p0-p1-fixes`, all 8 pass.
