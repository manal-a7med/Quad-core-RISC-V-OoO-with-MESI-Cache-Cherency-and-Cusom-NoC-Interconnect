# Archived reports

These two reports came with the imported repository
([Ratan-Y-Mallya/Major-project](https://github.com/Ratan-Y-Mallya/Major-project)).
They describe the design **before** this project's work and are kept only as
a record of the starting point. Many of their statements are no longer true
(for example "superscalar", static not-taken prediction, the inclusive L2,
the area and clock figures). Do not quote them.

The current description of the design is [../architecture.md](../architecture.md);
what changed and why is in [../scope.md](../scope.md) and [../bugs.md](../bugs.md).
