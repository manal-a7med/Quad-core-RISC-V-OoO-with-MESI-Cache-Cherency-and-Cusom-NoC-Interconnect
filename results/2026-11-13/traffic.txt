# Synthetic load (make traffic), RTL of the commit that added this file. verif/traffic/tb_traffic.v drives the four
# L1D CPU ports directly, 500 accesses per port, 30% stores. Same L1s, L2 and memory in every build.
# noc1 = one home at node 0, noc4 = a home per node, _f256 = 256-bit flits. In the hotspot pattern both lines
# have the same home (node 0), so noc1 and noc4 are the same there.
